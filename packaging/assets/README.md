# Packaging & Branding Assets

CC0-licensed branding graphics and assets for Windows Installer (`.msi`) synthesis.

Canonical copies of these assets reside in the companion CC0 assets repository
(`../cc0-assets/libscript/<stack>/assets/`) and are staged or synthesized dynamically during
packaging builds:

- `openedx.ico`: Multi-resolution Windows icon (16x16, 32x32, 48x48, 256x256).
- `openedx_lms.ico`: Open edX Learning Management System shortcut icon.
- `openedx_studio.ico`: Open edX Studio course authoring shortcut icon.
- `openedx_banner_top.bmp`: 493x58 24-bit bitmap banner for WiX installer top header.
- `openedx_banner_side.bmp`: 164x312 24-bit bitmap splash graphic for WiX dialog sidebar.
- `openedx_eula.rtf`: Open edX EULA terms formatted in Rich Text Format.
- `wordpress.ico`: Multi-resolution WordPress Windows icon.
- `wordpress_cli.ico`: WordPress Management Console shortcut icon.
- `wordpress_health.ico`: WordPress Diagnostics & Healthcheck shortcut icon.
- `wordpress_db.ico`: WordPress Database Console shortcut icon.
- `wordpress_backup.ico`: WordPress Backup Utility shortcut icon.
- `wordpress_banner_top.bmp`: 493x58 24-bit bitmap banner for WordPress WiX installer top header.
- `wordpress_banner_side.bmp`: 164x312 24-bit bitmap splash graphic for WordPress WiX dialog
  sidebar.
- `wordpress_eula.rtf`: WordPress EULA terms formatted in Rich Text Format.
