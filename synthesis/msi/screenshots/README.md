# Automated Installer Verification Screenshots (`synthesis/msi/screenshots/`)

## Overview

`synthesis/msi/screenshots/` stores reference and captured GUI/TUI wizard screenshots generated by
`devtools/capture_msi_vagrant_matrix.{sh,cmd}`, `devtools/capture_msi_live_screenshots.{sh,cmd}`,
and `devtools/verify_screenshots.{sh,cmd}` across Simple, Advanced, Online, and Offline `.msi` and
`msi-rs` live installer stages.
