# DOS Modular Distribution Synthesizer (`synthesis/distro/dos/`)

Synthesizes reproducible, rootless bootable **FreeDOS** (`1.3`, `1.4`) and **Microsoft MIT MS-DOS**
(`1.25`, `2.0`, `4.00`) floppy (`FAT12`) and partitioned hard-disk (`FAT16 BIGDOS` / `FAT32 LBA`)
images from declarative profiles (`synthesis/schemas/execution-plan.dos.schema.json`).
