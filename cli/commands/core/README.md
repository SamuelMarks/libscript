# LibScript Core Commands

## Overview

Provides primary CLI operations for searching, listing, and inspecting LibScript components.

## Subcommands

- `list`: Lists all available components categorized by domain.
- `search <query>`: Searches component manifests for keywords and matching tags.
- `semver`: Semantic version comparison utilities.
- `which <pkg> [ver]`: Prints the absolute installation path for a component version.
