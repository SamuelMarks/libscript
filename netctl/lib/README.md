# Netctl Network Configuration Modules

## Overview

Modular reverse proxy, server block, and virtual host generators used by `netctl`:

- `apache.sh`: Apache HTTP server configuration.
- `caddy.sh`: Caddyfile block generation.
- `nginx.sh`: Nginx server and location block management.
- `iis.sh`: Microsoft IIS site definitions.
- `vagrantfile.sh` / `dockerfile.sh`: Container and VM port forwarding mapping.
