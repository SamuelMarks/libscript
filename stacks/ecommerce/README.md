# Ecommerce Stacks

This directory contains pre-configured application stack definitions and orchestration workflows for
ecommerce solutions in LibScript.

## Available Stacks

- **[magento](magento/)**: This component installs and configures Magento.
- **[prestashop](prestashop/)**: This module automates the setup of PrestaShop.
- **[woocommerce](woocommerce/)**: WooCommerce is a customizable, open-source eCommerce platform
  built on WordPress.

## Usage

To provision and run any stack in this category:

```sh
./libscript.sh run <stack-name> latest
```
