# Networking Stacks

This directory contains pre-configured application stack definitions and orchestration workflows for
networking solutions in LibScript.

## Available Stacks

- **[openvpn](openvpn/)**: This document describes the `openvpn` networking and VPN component within
  the LibScript ecosystem.

## Usage

To provision and run any stack in this category:

```sh
./libscript.sh run <stack-name> latest
```
