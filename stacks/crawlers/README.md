# Crawlers Stacks

This directory contains pre-configured application stack definitions and orchestration workflows for
crawlers solutions in LibScript.

## Available Stacks

- **[firecrawl](firecrawl/)**: This document describes the `firecrawl` web scraping and crawling
  component within the LibScript

## Usage

To provision and run any stack in this category:

```sh
./libscript.sh run <stack-name> latest
```
