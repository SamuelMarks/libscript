# Vagrant Environment: Alpine Linux 3.24 (`vagrant/alpine-3.24/`)

## Overview

Pre-configured Vagrant environment (`bento/alpine-3.24`) used for musl libc, OpenRC, and `apk`
verification.

## Usage

```sh
cd vagrant/alpine-3.24
vagrant up
vagrant ssh
```

See [`../../VAGRANT.md`](../../VAGRANT.md) for custom Bento (`multi-os-qemu-aarch64`) box building
and snapshot management instructions.
