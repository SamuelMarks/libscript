# Vagrant Environment: Windows Server 2025 (`vagrant/windows-server-2025/`)

## Overview

Pre-configured Vagrant environment (`bento/windows-2025`) exercising native
`libscript.cmd package-as` multi-kernel & OS bakery synthesis, `.cmd` batch parity, and Windows
service verification.

## Usage

```sh
cd vagrant/windows-server-2025
LIBSCRIPT_TEST_TARGET=package-as vagrant up
```
