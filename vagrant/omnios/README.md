# Vagrant Environment: OmniOS / illumos (`vagrant/omnios/`)

## Overview

Pre-configured Vagrant environment (`bento/omnios`) used for SunOS/illumos SMF, ZFS boot
environments, `pkgsrc`, and `illumos-distro` verification.

## Usage

```sh
cd vagrant/omnios
vagrant up
vagrant ssh
```

See [`../../VAGRANT.md`](../../VAGRANT.md) for custom Bento (`multi-os-qemu-aarch64`) box building
and snapshot management instructions.
