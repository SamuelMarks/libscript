# Documentation Web Template (`docs-web-template`)

## Overview

This directory contains HTML templates and layout components used to generate the static web
documentation site for LibScript.

## Structure

- `top.html`: Header layout, navigation bar, and metadata definitions.
- `bottom.html`: Footer layout, script imports, and copyright information.
- `usage.html`: Template snippet for command usage documentation.
- `assets/`: Static styling and web asset resources.

## Usage

Used by `devtools/generate_html_docs.sh` during documentation builds.
