# Static HTML Documentation Site Template (`docs-web-template/`)

## Overview

`docs-web-template/` holds the HTML header (`top.html`), footer (`bottom.html`), interactive usage
landing fragment (`usage.html`), and CSS/JS assets (`assets/`) consumed by
`devtools/generate_html_docs.{sh,cmd,ps1}` when compiling LibScript's Markdown documentation and
JSON Schemas into a standalone static website (`./docs/latest`).
