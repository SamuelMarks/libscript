# gemma-tpu-suite

## Overview

`gemma-tpu-suite` is a standalone Tier 1 LibScript empirical evaluation component orchestrating
zero-cost TPU Research Cloud (TFRC) benchmarks across all seven Gemma 4 ML framework/backend
configurations (`hf_transformers`, `pytorch_native`, `keras_jax`, `keras_tensorflow`,
`keras_pytorch`, `maxtext`, and `jax_native`).

## Usage

```sh
./libscript.sh install gemma-tpu-suite latest
./libscript.sh gemma-tpu-suite experiments --tfrc-config=./tfrc.policy.json --repo-dir=. --subsuites=E0,E1,E2,E3,E4
```

```cmd
call libscript.cmd install gemma-tpu-suite latest
call libscript.cmd gemma-tpu-suite experiments "--tfrc-config=tfrc.policy.json" "--repo-dir=." "--subsuites=E0,E1,E2,E3,E4"
```
