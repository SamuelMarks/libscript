# Argp Standalone

Hierarchical argument parsing library for musl libc.

## Purpose & Current State

This document provides context and technical details for the **Argp Standalone** component (part of
the `base-system` module) within the LibScript ecosystem. It provides GNU-compatible argp interface
routines for systems linking against musl libc.

## Usage

You can install this component using the global `libscript` command.

**Unix (Linux/macOS):**

```sh
./libscript.sh install argp-standalone
```

**Windows:**

```cmd
libscript.cmd install argp-standalone
```
