# BusyBox

Swiss Army Knife of embedded Linux utilities.

## Purpose & Current State

This document provides context and technical details for the **BusyBox** component (part of the
`base-system` module) within the LibScript ecosystem. BusyBox combines tiny versions of many common
UNIX utilities into a single multi-call binary.

## Usage

You can install this component using the global `libscript` command.

**Unix (Linux/macOS):**

```sh
./libscript.sh install busybox
```

**Windows:**

```cmd
libscript.cmd install busybox
```
