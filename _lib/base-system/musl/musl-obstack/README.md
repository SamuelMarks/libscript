# Musl Obstack

GNU obstack library standalone port for musl.

## Purpose & Current State

This document provides context and technical details for the **Musl Obstack** component (part of the
`base-system` module) within the LibScript ecosystem. It provides the obstack memory allocation pool
interface for musl-based builds.

## Usage

You can install this component using the global `libscript` command.

**Unix (Linux/macOS):**

```sh
./libscript.sh install musl-obstack
```

**Windows:**

```cmd
libscript.cmd install musl-obstack
```
