# gettext-tiny

Lightweight internationalization shim for musl libc.

## Purpose & Current State

This document provides context and technical details for the **gettext-tiny** component (part of the
`base-system` module) within the LibScript ecosystem. gettext-tiny provides a lightweight
replacement for GNU gettext tools and libintl.

## Usage

You can install this component using the global `libscript` command.

**Unix (Linux/macOS):**

```sh
./libscript.sh install gettext-tiny
```

**Windows:**

```cmd
libscript.cmd install gettext-tiny
```
