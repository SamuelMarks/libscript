# Toybox

BSD-licensed POSIX all-in-one command suite.

## Purpose & Current State

This document provides context and technical details for the **Toybox** component (part of the
`base-system` module) within the LibScript ecosystem. Toybox provides BSD-licensed implementations
of standard command line utilities.

## Usage

You can install this component using the global `libscript` command.

**Unix (Linux/macOS):**

```sh
./libscript.sh install toybox
```

**Windows:**

```cmd
libscript.cmd install toybox
```
