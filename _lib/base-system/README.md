# Base System

## Purpose & Overview

This directory houses the **Base System** components within the LibScript ecosystem.

## Usage

You can install and manage components in this category using the global `libscript` command.

```sh
./libscript.sh install base-system
```

## Platform Support

- Linux
- macOS
- Windows
