# Graphics

## Purpose & Overview

This directory houses the **Graphics** components within the LibScript ecosystem.

## Usage

You can install and manage components in this category using the global `libscript` command.

```sh
./libscript.sh install graphics
```

## Platform Support

- Linux
- macOS
- Windows
