# Audio

## Purpose & Overview

This directory houses the **Audio** components within the LibScript ecosystem.

## Usage

You can install and manage components in this category using the global `libscript` command.

```sh
./libscript.sh install audio
```

## Platform Support

- Linux
- macOS
- Windows
