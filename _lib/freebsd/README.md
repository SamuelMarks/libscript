# Freebsd

## Purpose & Overview

This directory houses the **Freebsd** components within the LibScript ecosystem.

## Usage

You can install and manage components in this category using the global `libscript` command.

```sh
./libscript.sh install freebsd
```

## Platform Support

- Linux
- macOS
- Windows
