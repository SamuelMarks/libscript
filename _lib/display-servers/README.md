# Display Servers

## Purpose & Overview

This directory houses the **Display Servers** components within the LibScript ecosystem.

## Usage

You can install and manage components in this category using the global `libscript` command.

```sh
./libscript.sh install display-servers
```

## Platform Support

- Linux
- macOS
- Windows
