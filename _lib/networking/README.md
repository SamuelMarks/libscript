# Networking

## Purpose & Overview

This directory houses the **Networking** components within the LibScript ecosystem.

## Usage

You can install and manage components in this category using the global `libscript` command.

```sh
./libscript.sh install networking
```

## Platform Support

- Linux
- macOS
- Windows
