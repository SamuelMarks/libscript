# WordPress 7.1.2 Installer & Browser Verification Screenshots (`SCREENSHOTS.md`)

## Overview

This document catalogs the end-to-end visual verification gallery for the **WordPress 7.1.2
Platform** (`_lib/web-apps/wordpress`) generated by LibScript's schema-driven
`devtools/capture_running_system.sh` / `.cmd` pipeline and
[`SamuelMarks/msi-rs`](https://github.com/SamuelMarks/msi-rs).

All visual assets and window-cropped screenshots are archived under CC0-1.0 in the
[`SamuelMarks/cc0-assets`](https://github.com/SamuelMarks/cc0-assets/tree/master/libscript/wordpress)
repository:

  [`https://github.com/SamuelMarks/cc0-assets/tree/master/libscript/wordpress/assets`](https://github.com/SamuelMarks/cc0-assets/tree/master/libscript/wordpress/assets)

## 5. Reproducing & Verifying Screenshots

```sh
# Capture all WordPress installer wizard stages and wp-admin browser views across all 5 OS families:
./devtools/capture_wordpress_screenshots.sh --os all --variant both --flow both --mode all

# Verify PNG headers, non-empty sizes, and window-cropped bounding boxes:
./devtools/verify_screenshots.sh --target wordpress
```

On Windows (`cmd.exe`):

```cmd
call devtools\capture_wordpress_screenshots.cmd --os all --variant both --flow both --mode all
call devtools\verify_screenshots.cmd --target wordpress
```
