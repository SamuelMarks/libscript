# Open edX Installer & Browser Verification Screenshots (`SCREENSHOTS.md`)

## Overview

This document catalogs the end-to-end visual verification gallery for the **Open edX Platform**
(`_lib/web-apps/openedx`) generated by LibScript's schema-driven
`devtools/capture_running_system.sh` / `.cmd` pipeline and
[`SamuelMarks/msi-rs`](https://github.com/SamuelMarks/msi-rs).

All visual assets and window-cropped screenshots are archived under CC0-1.0 in the
[`SamuelMarks/cc0-assets`](https://github.com/SamuelMarks/cc0-assets/tree/master/libscript/openedx)
repository:

## 5. Reproducing & Verifying Screenshots

```sh
# Capture all Open edX installer wizard stages and browser views across all 5 OS families:
./devtools/capture_openedx_screenshots.sh --os all --variant both --flow both --mode all

# Verify PNG headers, non-empty sizes, and window-cropped bounding boxes:
./devtools/verify_screenshots.sh --target openedx
```

On Windows (`cmd.exe`):

```cmd
call devtools\capture_openedx_screenshots.cmd --os all --variant both --flow both --mode all
call devtools\verify_screenshots.cmd --target openedx
```
