# Tier 3.5 HA Topology Blueprint: `k0s-ha`

## Overview

Turnkey multi-node high-availability topology blueprint for `k0s-ha` orchestrated by
`topologies/engine.sh` and `topologies/engine.cmd`.

## Usage

```sh
./topologies/k0s-ha/cli.sh up
./topologies/k0s-ha/cli.sh status
./topologies/k0s-ha/cli.sh destroy
```
