# Tier 3.5 HA Topology Blueprint: `postgres-ha`

## Overview

Turnkey multi-node high-availability topology blueprint for `postgres-ha` orchestrated by
`topologies/engine.sh` and `topologies/engine.cmd`.

## Usage

```sh
./topologies/postgres-ha/cli.sh up
./topologies/postgres-ha/cli.sh status
./topologies/postgres-ha/cli.sh destroy
```
