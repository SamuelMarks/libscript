# Tier 3.5 HA Topology Blueprint: `valkey-cluster`

## Overview

Turnkey multi-node high-availability topology blueprint for `valkey-cluster` orchestrated by
`topologies/engine.sh` and `topologies/engine.cmd`.

## Usage

```sh
./topologies/valkey-cluster/cli.sh up
./topologies/valkey-cluster/cli.sh status
./topologies/valkey-cluster/cli.sh destroy
```
